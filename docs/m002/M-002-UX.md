# M-002 — Contrat UX

**Statut : RECADRÉ — création immédiate contrôlée ; gouvernance globale sans file de validation — 2026-09-23**

## 1. Page Workspace Produits

Route :

```text
/workspaces/:workspaceId/products
```

Deux vues :

```text
Référentiel global
Mon référentiel
```

### Référentiel global

Vue proposée en premier lorsque la capability `product_reference_access` est disponible.

Affiche les Produits/déclinaisons `ACTIVE` globaux.

Actions :

- recherche prédictive puis recherche explicite ;
- filtrage par catégorie ;
- ouvrir le détail ;
- ajouter à Mon référentiel via l'action `+` ;
- retirer de Mon référentiel via l'action `−` lorsqu'une référence y est déjà présente ;
- créer un Produit si aucun équivalent crédible n'existe.

La table affiche `Produit | Présentation | Gamme | Actions`. Elle n'affiche ni colonne supplémentaire « Mon référentiel », ni colonne Statut ACTIVE redondante : les actions `+` / `−` et le scope portent déjà ces informations. Les résultats sont triés alphabétiquement par Produit avant pagination.

### Mon référentiel

Affiche uniquement les déclinaisons actuellement rattachées au Workspace.

Actions selon droits :

- recherche prédictive ;
- filtrage par catégorie ;
- ouvrir le détail ;
- retirer de Mon référentiel ;
- importer ;
- créer un Produit.

Aucun filtre d'état « Dans / Retiré » n'est affiché : l'onglet représente déjà la sélection active du Workspace et une référence retirée reste retrouvable dans le Référentiel global pour être réajoutée.

Il n'existe plus de références « En validation ».

## 2. Création d'un Produit

Libellé utilisateur :

```text
Créer un Produit
```

Le parcours reste guidé :

### Étape 1 — Vérifier l'existant

- recherche exacte ;
- candidats proches ;
- alias et similitudes ;
- choix possible d'une référence existante.

### Étape 2 — Identité

Si aucun équivalent n'est retenu :

- nom canonique ;
- alias facultatifs ;
- catégorie obligatoire.

### Étape 3 — Première déclinaison

- Présentation ;
- Gamme obligatoire, alimentée par les métadonnées backend ;
- État / transformation dépendant de la Gamme, prérempli et proposé en autocomplétion ;
- unité de référence ;
- rendement facultatif.

Le champ Conservation n'est plus affiché.

Confirmation :

```text
Créer et ajouter à mon référentiel
```

Résultat :

```text
CanonicalProduct ACTIVE
+ ProductVariant ACTIVE
+ WorkspaceProduct ACTIVE
```

Aucun message « Envoyé en validation » n'est affiché.

## 3. Ajout d'une déclinaison

Depuis un Produit existant :

- afficher les déclinaisons existantes ;
- vérifier la signature ;
- créer uniquement si aucune déclinaison équivalente n'existe ;
- nouvelle déclinaison immédiatement ACTIVE ;
- rattachement au référentiel du Workspace créateur.

## 4. Empty states

Mon référentiel vide :

« Recherchez le référentiel global ou créez votre premier Produit. »

Référentiel sans résultat :

« Aucun produit correspondant. Vérifiez les suggestions avant de créer une nouvelle référence. »

Les actions affichées doivent toujours correspondre aux permissions/capabilities effectives.

## 5. Import Workspace

Bouton :

```text
Importer
```

Parcours :

```text
Téléverser
→ associer les colonnes
→ vérifier les correspondances
→ confirmer
```

La preview distingue :

- références existantes à rattacher ;
- déclinaisons existantes ;
- nouvelles déclinaisons à créer ;
- nouveaux Produits à créer ;
- correspondances proches nécessitant une décision ;
- lignes invalides ;
- colonnes M-003 détectées.

Les termes « proposé », « contribution envoyée » et « en validation » disparaissent.

## 6. Administration globale du référentiel

Route métier globale :

```text
/product-reference
```

Elle reste hors `PlatformLayout`.

L'accès dépend des permissions Application Global Produit.

Navigation :

```text
Référentiel
Catégories
```

La section « À valider » est supprimée.

### Référentiel

Fonctions selon `product:reference:manage` :

- créer un Produit ;
- ajouter une déclinaison ;
- importer des Produits génériques ;
- corriger ;
- archiver/réactiver ;
- consulter l'historique.

Une personne de l'équipe Platform explicitement habilitée par Application Global peut utiliser cette surface.

### Catégories

- créer ;
- renommer ;
- archiver/réactiver ;
- empêcher l'archivage d'une catégorie encore utilisée par un Produit ACTIVE.

## 7. Vocabulaire utilisateur

À utiliser :

- Produit ;
- Déclinaison ;
- Présentation ;
- Gamme ;
- État / transformation ;
- Référentiel global ;
- Mon référentiel ;
- Créer un Produit ;
- Ajouter une déclinaison ;
- Ajouter à mon référentiel ;
- Retirer de mon référentiel ;
- Importer ;
- Archiver ;
- Réactiver.

Le terme « catalogue » est réservé aux catalogues fournisseurs du périmètre M-003.

À supprimer du parcours courant :

- Proposer un Produit ;
- Envoyer en validation ;
- En validation ;
- À valider ;
- Rejeter une contribution.

## 8. Frontière M-003

L'interface M-002 peut signaler qu'un fichier ressemble à un catalogue fournisseur, mais n'affiche pas encore de filtre Fournisseur/Catalogue.

Ces concepts seront traités en M-003 :

```text
Fournisseur
→ Catalogue fournisseur identifié/versionné
→ Article fournisseur
→ rattachement à ProductVariant
```

La provenance fournisseur ne doit jamais être perdue lors d'un futur import M-003.
