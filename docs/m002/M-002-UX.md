# M-002 — Contrat UX proposé

**Statut : PROPOSÉ — à valider avant implémentation frontend**

## 1. Navigation Workspace

Nouvelle entrée :

```text
Produits
```

Route :

```text
/workspaces/:workspaceId/products
```

Visible avec `product:read`.

## 2. Page Produits

Deux portées principales :

```text
Mon catalogue
Tout le référentiel
```

### Mon catalogue

Affiche les déclinaisons rattachées au Workspace.

Fonctions :

- recherche ;
- catégorie ;
- statut de rattachement ;
- pagination serveur ;
- ouverture du détail ;
- retirer/réactiver selon permission.

### Tout le référentiel

Affiche :

- Produits/déclinaisons ACTIVE globaux ;
- contributions PENDING appartenant au Workspace courant.

Fonctions :

- recherche ;
- catégorie ;
- filtres ;
- rattacher au catalogue ;
- contribuer si aucun résultat crédible.

Aucune donnée privée d'un autre Workspace n'apparaît.

## 3. Présentation d'une ligne

Données utiles :

- nom Produit ;
- libellé de déclinaison ;
- catégorie ;
- unité de référence ;
- rendement si connu ;
- gamme si applicable ;
- statut ;
- état « Dans mon catalogue ».

Le libellé de déclinaison est composé pour l'affichage à partir des champs structurés ; il n'est pas une seconde identité libre concurrente.

## 4. Drawer Produit

Surface de consultation :

```text
Produit
Déclinaisons
Catalogue
```

Il permet de comprendre :

- identité canonique ;
- alias ;
- catégorie ;
- déclinaisons ;
- statut de gouvernance ;
- rattachement au Workspace.

Les modifications globales ne sont pas proposées à un simple utilisateur Workspace.

## 5. Contribution

Dialog guidé en trois blocs dans une seule interaction :

### Étape 1 — Vérifier l'existant

- nom recherché ;
- exact match ;
- candidats proches ;
- possibilité de choisir l'existant.

### Étape 2 — Identité

Uniquement si aucun équivalent n'est retenu :

- nom canonique ;
- alias facultatifs.

### Étape 3 — Première déclinaison

- forme ;
- état/transformation ;
- conservation ;
- gamme facultative ;
- unité de référence ;
- rendement facultatif.

Soumission :

```text
Contribution envoyée
→ visible dans Mon catalogue
→ badge En validation
→ non disponible comme référence globale ACTIVE avant validation
```

## 6. Ajout d'une déclinaison

Depuis un Produit existant :

- afficher les déclinaisons existantes ;
- rechercher avant création ;
- proposer une nouvelle déclinaison seulement si aucune signature équivalente n'existe.

## 7. États UX

### Empty

Mon catalogue vide :

« Aucun produit dans votre catalogue. Recherchez le référentiel pour ajouter vos premiers produits. »

Référentiel sans résultat :

« Aucun produit correspondant. Vérifiez les suggestions avant de proposer une nouvelle référence. »

### Loading

Skeletons ou état textuel cohérent avec les primitives existantes.

### Error

`ErrorState` avec `Réessayer` uniquement sur une vraie erreur de chargement.

Un résultat vide ou une contribution en attente n'est pas une erreur.

## 8. Plateforme

Route proposée :

```text
/platform/products
```

Une seule page avec onglets :

```text
À valider
Référentiel
Catégories
```

### À valider

- contributions PENDING ;
- comparaison avec candidats proches ;
- correction des champs partagés ;
- approbation ;
- rejet avec motif et remplacement éventuel.

### Référentiel

- recherche globale ;
- actifs/archivés ;
- correction ;
- archivage/réactivation ;
- remplacement informatif.

### Catégories

- créer ;
- renommer ;
- archiver/réactiver ;
- empêcher l'archivage d'une catégorie encore utilisée par un Produit ACTIVE.

## 9. Dashboard Workspace

Widget M-002 proposé :

```text
Catalogue Produits
→ nombre d'entrées actives du Workspace
→ contributions en validation
→ accès direct à Produits
```

Le widget est filtré par `product:read`.

Il est configurable et ne remplace pas la page Catalogue.

## 10. Dossier

M-002 ne crée pas un second catalogue par Dossier.

La page Dossier reste compatible avec le futur usage du catalogue Workspace mais n'affiche pas encore de prix, fournisseur ou disponibilité locale.

## 11. Vocabulaire utilisateur

Interface française :

- Espace de travail ;
- Produit ;
- Déclinaison ;
- Mon catalogue ;
- Référentiel ;
- Ajouter au catalogue ;
- Retirer du catalogue ;
- En validation.

Les noms techniques `WorkspaceProduct`, `CanonicalProduct`, `ProductVariant` et `grant` restent hors des libellés utilisateur.
